## Further Learning

Interested in deepening your knowledge about GPU programming?
Check out this selection of the diverse courses portfolio offered by NHR@FAU and collaborating institutions:
* CUDA
  * [Fundamentals of Accelerated Computing with CUDA C/C++](https://go-nhr.de/course-dli-cuda-c-cpp)
  * [Scaling CUDA-Accelerated Applications](https://go-nhr.de/course-scaling-cuda)
* Thrust (and some CUDA): [Fundamentals of Accelerated Computing with Modern CUDA C++](https://go-nhr.de/course-dli-modern-cuda)
* OpenMP
  * [Introduction to Parallel Programming with OpenMP](https://go-nhr.de/course-openmp) (incl. target offloading)
  * [Fundamentals of Accelerated Computing with OpenMP](https://go-nhr.de/course-openmp-offloading)
* OpenACC: [Fundamentals of Accelerated Computing with OpenACC](https://go-nhr.de/course-dli-openacc)
* Kokkos: [Fundamentals of Accelerated Computing with Kokkos](https://go-nhr.de/course-kokkos)
* [GPU Performance Engineering](https://go-nhr.de/course-gpu-performance-engineering)
